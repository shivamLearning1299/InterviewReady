# Alembic revision scripts live here.

Revision files are generated with:

    alembic revision --autogenerate -m "add <thing>"

and applied with:

    alembic upgrade head

Destructive autogenerated operations (DROP TABLE / DROP COLUMN / DROP INDEX /
DROP CONSTRAINT) are rejected unless `ALLOW_DESTRUCTIVE_MIGRATIONS=1` is set, so no
migration can silently remove an existing Supabase table or user data.
